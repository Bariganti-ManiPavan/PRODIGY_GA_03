# PRODIGY_GA_03: Text Generation with Markov Chains

## Project Overview
This repository contains **Task-03** completed during my **Generative AI Internship** at **Prodigy Infotech**. The objective of this task is to implement a simple statistical text generation algorithm using **Markov Chains**.

The model analyzes a given sample text, builds a probability dictionary (chain) of words, and predicts/generates new coherent sentences based on the state of the previous word(s).

## Key Features
* **Zero External Dependencies:** Built purely using Python's built-in `random` and `collections` modules.
* **Statistical Modeling:** Implements a First-order Markov Chain (`state_size=1`) to calculate next-word probabilities.
* **Custom Text Generation:** Generates unique, automated content based on the training dataset provided.
